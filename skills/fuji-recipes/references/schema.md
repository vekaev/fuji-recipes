# Recipe file

One JSON file per recipe: `$FUJI_RECIPES/recipes/<slug>.json` (default `~/Documents/FujiRecipes`). The
file is the source of truth; `library.md` is generated by `fuji` (fuji index). The future Mac / iPhone
app reads the same folder, so keep the field names and value spellings exactly as below.

```json
{
  "slug": "summer-chrome",
  "name": "Summer Chrome",
  "status": "to-try",
  "settings": {
    "film": "Classic Chrome",
    "grain_roughness": "Weak", "grain_size": "Small",
    "color_chrome": "Strong", "color_chrome_fx_blue": "Weak",
    "wb": "Daylight", "wb_kelvin": null, "wb_red": 2, "wb_blue": -4,
    "dynamic_range": "DR200", "d_range_priority": "Off",
    "highlight": -1, "shadow": 1,
    "color": 2, "mono_warm_cool": null, "mono_magenta_green": null,
    "sharpness": -1, "high_iso_nr": -4, "clarity": 0
  },
  "shooting": { "iso": "Auto, up to 6400", "exposure_compensation": "+1/3 to +2/3", "notes": "" },
  "sensors": ["X-Trans IV", "X-Trans V"],
  "source": { "kind": "reel", "url": "https://www.instagram.com/reel/…", "creator": "@handle",
              "credit": "Recipe by …", "transcript": "~/Downloads/transcripts/handle-id.md",
              "date_added": "2026-11-04" },
  "uncertain": ["settings.wb_blue", "settings.clarity"],
  "shots": 0, "cameras": [], "first_shot": null, "last_shot": null,
  "samples": [],
  "notes": ""
}
```

## Values

| Field | Values |
|---|---|
| `film` | `Provia`, `Velvia`, `Astia`, `Classic Chrome`, `Reala Ace`, `Pro Neg. Hi`, `Pro Neg. Std`, `Classic Neg.`, `Nostalgic Neg.`, `Eterna`, `Eterna Bleach Bypass`, `Acros`, `Acros+Ye`, `Acros+R`, `Acros+G`, `Monochrome`, `Monochrome+Ye`, `Monochrome+R`, `Monochrome+G`, `Sepia` |
| `grain_roughness` | `Off`, `Weak`, `Strong` |
| `grain_size` | `Off` (when roughness is Off), `Small`, `Large` |
| `color_chrome`, `color_chrome_fx_blue` | `Off`, `Weak`, `Strong` |
| `wb` | `Auto`, `Auto White Priority`, `Auto Ambience Priority`, `Daylight`, `Shade`, `Fluorescent 1`, `Fluorescent 2`, `Fluorescent 3`, `Incandescent`, `Underwater`, `Kelvin` (then `wb_kelvin` 2500–10000) |
| `wb_red`, `wb_blue` | −9 … +9 (the camera's WB Shift; EXIF stores it ×20) |
| `dynamic_range` | `Auto`, `DR100`, `DR200`, `DR400` |
| `d_range_priority` | `Off`, `Auto`, `Weak`, `Strong` (when not Off, DR and tone are set by the camera) |
| `highlight`, `shadow` | −2 … +4 in 0.5 steps |
| `color` | −4 … +4; `null` for monochrome films |
| `mono_warm_cool`, `mono_magenta_green` | −9 … +9 for Acros / Monochrome / Sepia; `null` for colour films |
| `sharpness`, `high_iso_nr` | −4 … +4 |
| `clarity` | −5 … +5 (store the creator's value; while the library's Clarity preference is off, the default, the camera gets 0, because any other value makes every shot wait 1–3 s to be stored) |
| `status` | `mine` (shot with it, found in EXIF), `to-try`, `tried`, `favorite`, `rejected` |

Not stored in a camera slot, so they live in `shooting`: ISO, exposure compensation, lens or filter advice.
A field the source doesn't give keeps the camera default (0 / Off / Auto) and goes into `uncertain`.

## Recipe text format (for copy / paste and reading captions)

```
Film Simulation: Classic Chrome
Grain Effect: Weak, Small
Color Chrome Effect: Strong
Color Chrome FX Blue: Weak
White Balance: Daylight, +2 Red & -4 Blue
Dynamic Range: DR200
Highlight: -1
Shadow: +1
Color: +2
Sharpness: -1
High ISO NR: -4
Clarity: 0
ISO: Auto, up to ISO 6400
Exposure Compensation: +1/3 to +2/3
```

Creators abbreviate: "CC" can mean Classic Chrome (film) or Color Chrome (effect) — decide by position
and context; "CCFXB" / "FX Blue"; "WB 5500K"; "R+2 B-4" / "+2R -4B"; "DR-P" = D-Range Priority;
"H-1 S+1" = highlight / shadow tone; "NR -4"; "Grain W/S" = weak, small.
