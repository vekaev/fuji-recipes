# Glossary

- **Recipe**: a named set of in-camera JPEG settings (film simulation, grain, colour chrome, white balance + shift,
  dynamic range, tone, colour, sharpness, NR, clarity). One file in `recipes/`.
- **Look**: what a recipe does to photos. Shown, never imitated: camera-rendered scenes, your photos, creator frames.
- **Slot**: a place on the camera that holds one recipe: **C1–C7** (custom settings, picked with Q while the dial is
  on C) and **FS1–FS3** (film simulation dial positions). "Bank" is the protocol's word for a C slot.
- **Reference scenes**: 3–6 of the owner's own RAW + JPEG shots (bright, indoor, detail, …) that every recipe is
  rendered on, so looks compare fairly.
- **Slot history**: what a slot held before each change, with dates; "Put back" restores an entry.
- **Inbox**: links and screenshots waiting to become recipes; each ends Kept (a recipe, status to-try) or Skipped.
- **Kit**: a named set of recipes for C1–C7, written in one go.
- **Write**: changing the camera. Always: review "now → new", backup of every slot, write, read back.
- **Doctor**: the five-step connection check (USB → camera → session → mode → slots).
- **Status**: mine (shot with it), favorite, tried, to-try, rejected.
